# Yifei Zhang — Personal Site

Personal academic homepage. Plain HTML/CSS/JS, no build step, hosted on GitHub Pages.

Live at: https://glitterzhang.github.io/yifeizhang-page/

## Files

- `index.html` — page content
- `style.css` — layout and colors (`--accent` in `:root` sets the theme color)
- `script.js` — nav scroll-highlighting, mobile menu, email-copy button
- `assets/` — profile photo
